# FruitAPI

<sub>Documentation drafted with claude.ai</sub>

A .NET 8 Minimal API for a fruit catalogue, backed by EF Core.

## Endpoints

    GET    /fruits
    GET    /fruits/{id}
    POST   /fruits
    PUT    /fruits/{id}
    DELETE /fruits/{id}

## Running it

    dotnet run

Built while working through the ASP.NET Core Minimal API material, as the API half
of a pair - the companion Blazor front end is in `FruitWebApp-codebehind`.
